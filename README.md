# MIBO Core

MIBO Core is the authoritative repository for the fixed sentinel panel survey of public generative-AI information behavior.

## First-year design

- four persistent public service lineages;
- 12 conceptual items and 24 Japanese/English query forms;
- 12 monthly synchronized waves;
- ten independent replications per required cell;
- a separate paired API Live–Frozen module;
- four English Anchor Items; and
- multisite re-observability calibration.

## Status

The current package is **v1.0-rc3**, an integrated release candidate for institutional review, dry runs, mirror-site recruitment, and preregistration preparation. It is not the final preregistered v1.0 release.

MIBO is composed of **MIBO Core, MIBO Satellite, and MIBO Network**.
