## Unchanged descriptive measure

Use citation URLs first, then the literal displayed-text URL rule from v1.0;
trim trailing periods/commas/semicolons, deduplicate in encounter order, keep
the first five, and summarize an order-insensitive set of exact strings.
No linked-page retrieval, redirects, query normalization, semantic source
merging or claim-support grading. URL-free bibliographies remain outside scope.

For each of six lineage/language cells, describe mean pairwise set Jaccard,
`|A ∩ B| / |A ∪ B|`. One empty set gives 0; two empty sets are undefined and
counted separately. No defined pairs means an undefined mean, never 0 or 1.
At n=10 there are 45 dependent pairs per cell, not 45 independent responses.
Include valid refusal/safety/nonanswers, exclude technical missingness from
valid-response denominators, retain intended n=10, and report actual n.
The inherited >=8 rule is reported without turning sparse cells into complete
ones. Distinct URL-set counts, URL-free share, lowercase exact hostname
Jaccard and hostname parse failures remain descriptive, with the same limits.
