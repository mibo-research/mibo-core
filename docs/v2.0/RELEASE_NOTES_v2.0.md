# Release Notes — MIBO Core Protocol Package v2.0

## Scientific change

MIBO Core v2.0 prospectively replaces the v1.0 human-operated consumer-interface
primary condition with a fully automated provider-API primary condition named
API Core Interface (`ACI`). It does not relabel API data as Ecological Live.

## Preserved elements

- the four service lineages;
- the exact 24 Japanese/English Query Forms and their hashes;
- `k=10` within-cell replication;
- the deterministic v1.0 seed formula;
- W01/W04/W07/W10 adjacent-window calibration structure;
- technical retry minimums and maximum of two retries;
- append-only raw capture and missingness without imputation; and
- the `.15` candidate, `.10` sustained, minimum-eight-cell, and `Phi >= .80`
  operating thresholds.

## New elements

- `ACI` as an explicitly separate API observation surface;
- four-provider fully automated collection, including Perplexity only with
  search disabled;
- a new 12-wave cycle beginning 6 October 2026;
- a dedicated v2.0 namespace and execution sentinel;
- exact model/settings freeze, official-catalog verification, synthetic smoke,
  and hash-bound human authorization before every wave; and
- an explicit public transition record stating that v1.0 W01 did not commence.

## Not represented as completed by publication

Publication of the protocol does not claim that the MIBO2-W01 Provider Freeze,
Terms/access review, synthetic smoke tests, execution authorization, or data
collection have occurred. Those are prospective private execution gates.
