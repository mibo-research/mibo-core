# MIBO Core v1.0 to v2.0 Transition Record

**Decision date:** 3 September 2026

**Prior protocol:** `10.5281/zenodo.21936410`

**Prospective successor:** MIBO Core API-only Observatory Protocol v2.0

## Decision

The planned v1.0 Japan-site W01 Ecological Live collection did not commence
inside its registered field window. The required private execution gate did not
close, and no v1.0 confirmatory observation is represented as successfully
collected.

The operational requirement for repeated human operation of consumer web
interfaces was determined to be infeasible for the available one-person
operation. This determination was made without using observed confirmatory
outputs to select a new method.

MIBO Core therefore moves prospectively to an API-only primary observation
surface beginning with `MIBO2-W01`, scheduled for 6 October 2026 00:00 UTC. The
new surface is identified as `ACI` and has a different estimand from v1.0
Ecological Live.

## Preservation of v1.0

The v1.0 Zenodo record, founding paper, public repository history, and private
append-only deviation record remain preserved. They are not withdrawn or
silently rewritten. The missed v1.0 start is not backfilled, and later API
observations are not assigned v1.0 identifiers.

The private late-start deviation already created for the missed W01 start is
retained under its original identifier and hash in the authoritative controlled
data store. The public transition record does not disclose restricted runtime
contents.

## Comparability statement

The fixed service-lineage panel and 24 Query Forms are reused to maintain
instrument continuity. Observation-surface continuity is not claimed.
Longitudinal confirmatory inference begins anew at the v2.0 baseline, and v1.0
contains no completed W01 baseline to be combined with it.
