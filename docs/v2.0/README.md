# MIBO Core Protocol Package v2.0

This directory contains the prospectively registered API-only successor to MIBO Core v1.0.
The version-specific release DOI is `10.5281/zenodo.22264635`.
The v1.0 scientific record remains authoritative for its own public-interface
design and is not modified by this package.

## Package contents

- `MIBO_Core_Protocol_v2.0.md` — scientific protocol and fixed first-cycle schedule;
- `MIBO_Operations_Manual_v2.0.md` — controlled-runtime field procedure;
- `MIBO_Statistical_Analysis_Plan_v2.0.md` — confirmatory analysis rules;
- `MIBO_v1_to_v2_Transition_Record.md` — prospective version-boundary record; and
- `MIBO_API_Terms_Access_Review_Template_v2.0.md` — public review template.

The release archive also includes machine-readable protocol, service, and
instrument files; private completed freezes, authorizations, keys, readiness
evidence, and raw observations are excluded.
