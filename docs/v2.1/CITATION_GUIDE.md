# Citation and version guide

The current published protocol is **Core v2.1**, published 7 November 2026,
DOI [10.5281/zenodo.24029860](https://doi.org/10.5281/zenodo.24029860).
Its declaration adopts the unchanged reviewed ZIP and W03 analysis v1.1.
Publication does not qualify AI scoring or authorize execution.

## Recommended protocol citation

Sasano, K. (2026). *MIBO Core Protocol Package v2.1: Three-Series API Observatory
and Reciprocal AI Coding* (Version 2.1). Zenodo.
https://doi.org/10.5281/zenodo.24029860

Use [published citation metadata](PUBLISHED_CITATION.cff) or the root
CITATION.cff **preferred-citation** block. That block directs GitHub's
"Cite this repository" to the formal published protocol.
See [GitHub's citation guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files).

The root fields retain the archived 2.1-draft preparation-template identity,
not the published protocol's status. The original offline draft audit and
execution guards stay intact.
