# MIBO Cross-Document Consistency Audit v1.0-rc3

**Audit date:** 3 August 2026  
**Scope:** Master Protocol and seven principal companion documents  
**Status:** Integrated release candidate; final technical and institutional freeze pending  

---

# 1. Overall Judgment

The MIBO first-year research design is internally coherent and retains its methodological identity as a sentinel panel survey.

The integrated design consistently specifies:

- four persistent public generative-AI service lineages;
- 12 conceptual items and 24 bilingual query forms;
- 12 monthly synchronized waves;
- ten independent replications per required cell;
- four English Anchor Items;
- four multisite calibration waves;
- a minimum of three eligible sites for site-level assessment;
- a public Ecological Live panel;
- a separate paired API Live–Frozen module;
- a joint absolute dependability threshold of .80;
- validated AI-assisted coding with 10% human audit; and
- no imputation of missing machine responses.

No unresolved contradiction remains that would prevent dry-run implementation.

---

# 2. Corrections Made in rc3

## 2.1 Frozen–Live observational modes

Earlier documents could be read as directly comparing the public web Live service with an API Frozen model.

rc3 now distinguishes:

1. **Ecological Live Line** — public web-interface panel observation;
2. **Paired Live Reference** — current API reference under the common harness; and
3. **Frozen Reference** — baseline API reference under the same harness.

Only the paired API conditions support Class A or Class B update contrasts.

## 2.2 H4 scope

The first-year primary paired module is environment-closed.

H4 is now explicitly conditional:

- it is assessed only if a matched environment-open stratum is preregistered before Wave 1;
- otherwise it is classified as not assessed; and
- Frozen temporal variation is not mislabeled as external information-environment change.

## 2.3 Japanese response-length rules

The Japanese query forms no longer use the ambiguous expressions “300-word equivalent” and “250-word equivalent.”

They now use:

- 600 Japanese characters for MIBO-I03; and
- 500 Japanese characters for MIBO-I07.

The Codebook defines the corresponding descriptive length metric.

## 2.4 Version synchronization

All principal documents and the Mirror Observatory Kit are synchronized as **v1.0-rc3**.

## 2.5 Mirror-site feasibility

The Mirror Kit now recommends at least two trained operators per 12-hour calibration window, with one operator per service preferred where feasible.

# 4. Remaining Freeze Gates

The integrated package must not yet be labeled final v1.0.

Formal v1.0 requires completion of:

1. institutional ethical-status determination;
2. terms-of-service and account review;
3. bilingual review of all 24 query forms;
4. Japan-site full dry run;
5. Frozen-model technical verification and final Class A/B/C decisions;
6. final selection of account tiers and public observation modes;
7. human-reference-set construction;
8. simulation review of the registered effect thresholds;
9. at least two prospective international-site dry runs;
10. data-custody and transfer arrangements;
11. named role assignments and approvals;
12. final repository deposit and persistent identifier;
13. final file hashes; and
14. an amendment decision on whether an environment-open H4 module will be included.

These are execution gates, not unresolved conceptual defects.

---

# 5. Final Recommendation

Use **v1.0-rc3** for:

- institutional review;
- technical dry runs;
- mirror-site recruitment;
- preregistration preparation; and
- final operational verification.

Promote the package to **v1.0** only after the remaining freeze gates have been completed and documented.

The core scientific design should not be expanded further before Wave 1.
